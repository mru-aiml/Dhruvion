# DHRUVION Backend

FastAPI backend for the DHRUVION Martian Mission Intelligence Platform.

## Quick Start

### Prerequisites
- Python 3.11+
- Virtual environment tool (venv)

### Setup

```bash
cd backend

# Create and activate virtual environment
python -m venv .venv

# Windows PowerShell:
.venv\Scripts\Activate.ps1

# macOS/Linux:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Configure environment (optional - defaults work for local dev)
cp .env.example .env
# Edit .env if needed
```

### Running the Server

```bash
# Development with auto-reload
uvicorn app.main:app --reload

# Production (without reload)
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

The API will be available at:
- **Root**: http://localhost:8000/
- **Health**: http://localhost:8000/health
- **API Docs (Swagger)**: http://localhost:8000/docs
- **API Docs (ReDoc)**: http://localhost:8000/redoc
- **OpenAPI Schema**: http://localhost:8000/openapi.json

## API Endpoints

All endpoints are under `/api` prefix.

### Health & Info
| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Service health check (independent of external services) |
| GET | `/` | API information and links |

### Regions & Layers
| Method | Path | Description |
|--------|------|-------------|
| GET | `/regions` | List supported regions |
| GET | `/layers?region_id={id}` | Layer catalog with provenance |

### Terrain & Hazards
| Method | Path | Description |
|--------|------|-------------|
| GET | `/terrain?region_id={id}&x={lon}&y={lat}` | Query terrain at coordinate |
| GET | `/hazards?region_id={id}` | Hazard features for region |

### Science Targets
| Method | Path | Description |
|--------|------|-------------|
| GET | `/targets?region_id={id}` | Science targets catalog |

### Route Planning
| Method | Path | Description |
|--------|------|-------------|
| POST | `/route/optimize` | Calculate route strategies (shortest, safest, balanced) |
| POST | `/mission/plan` | Create mission plan with time budget |
| POST | `/mission/return` | Evaluate return-to-base feasibility |
| POST | `/route/reroute` | Emergency reroute around obstruction |

### AI Assistant
| Method | Path | Description |
|--------|------|-------------|
| POST | `/assistant/ask` | Mission-aware assistant (tools not yet connected) |

### Mission Reports
| Method | Path | Description |
|--------|------|-------------|
| POST | `/mission/report` | Generate mission report |

### Authentication
| Method | Path | Description |
|--------|------|-------------|
| POST | `/auth/register` | Register new user |
| POST | `/auth/login` | Login user |
| POST | `/auth/logout` | Logout user |
| GET | `/auth/me` | Get current user session |

### Tile Proxy
| Method | Path | Description |
|--------|------|-------------|
| GET | `/tiles/{layer}/{z}/{x}/{y}.png` | Proxy NASA Mars Trek WMTS tiles |

## Environment Configuration

Create `.env` from `.env.example`:

```env
# Database
DATABASE_URL=sqlite:///./dhruvion.db

# JWT Authentication (REQUIRED for production)
JWT_SECRET_KEY=your-secure-random-string-here
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60
COOKIE_NAME=dhruvion_access_token

# CORS
FRONTEND_ORIGIN=http://localhost:5173

# Logging
LOG_LEVEL=INFO
```

### Generate Secure JWT Secret
```bash
# Linux/macOS
openssl rand -hex 32

# PowerShell
[System.Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }))
```

## Data Files

The backend expects processed MOLA data files at:
```
data/
└── processed/
    └── mola/
        └── gale/
            ├── elevation.tif
            ├── elevation.png
            ├── slope.tif
            ├── slope.png
            ├── roughness.tif
            └── roughness.png
```

These are generated by the processing scripts in `scripts/`. If missing, terrain queries will return `unavailable`.

## Key Design Principles

1. **Deterministic Core**: All geospatial calculations are pure Python functions
2. **Provenance by Design**: Every response includes data source and status
3. **Missing Data is Unknown**: NoData never coerced to zero
4. **Fail Safe**: Missing required data returns `UNVERIFIED`, never `FEASIBLE`
5. **Replaceable Adapters**: NASA data sources can be swapped without rewriting domain logic

## API Conventions

- Base path: `/api`
- Coordinate reference: `urn:ogc:def:crs:IAU2000::104905` (Mars equirectangular)
- All coordinates: `{x: longitude, y: latitude, crs: "..."}`
- Status values: `observed`, `derived`, `simulated`, `unavailable`
- Feasibility: `feasible`, `caution`, `not_feasible`, `unverified`
- Errors include `request_id` for tracing

## Development Notes

- Health endpoint is independent of external NASA services
- Tile proxy caches NASA Mars Trek WMTS tiles
- Structured logging with request IDs
- Centralized exception handling with consistent error codes
- Pydantic validation on all request/response bodies
