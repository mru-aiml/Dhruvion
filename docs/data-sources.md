# DHRUVION Data Sources and Attribution

This document catalogs all data sources used in the DHRUVION prototype, their provenance, processing steps, and attribution requirements.

## Overview

DHRUVION uses a combination of **observed** NASA datasets, **derived** products computed from observed data, and **simulated** mission context for demonstration purposes. Every data layer in the UI carries an explicit status badge.

## Status Definitions

| Status | Meaning | Color |
|--------|---------|-------|
| **OBSERVED** | Directly measured or recorded by instruments | Green |
| **DERIVED** | Computed from observed source data | Amber |
| **SIMULATED** | Scenario or decision-support output, not measured | Cyan |
| **UNAVAILABLE** | Not connected, outside coverage, or not implemented | Muted |

## Primary Data Sources

### 1. MGS MOLA MEGDR (Mars Orbiter Laser Altimeter)

| Property | Value |
|----------|-------|
| **Instrument** | Mars Orbiter Laser Altimeter (MOLA) on Mars Global Surveyor |
| **Product** | Mission Experiment Gridded Data Record (MEGDR) |
| **Resolution** | 128 pixels/degree (~463 m/pixel at equator) |
| **Coverage** | Global Mars |
| **Datum** | Mars sphere (3396 km radius), areoid reference |
| **Source** | NASA PDS Geosciences Node |
| **Access** | https://pds-geosciences.wustl.edu/missions/mgs/megdr.html |
| **Status in DHRUVION** | **OBSERVED** (basemap), **DERIVED** (elevation, slope, roughness) |

**Usage in DHRUVION:**
- Color-shaded relief basemap (observed)
- Elevation raster for Gale Crater region (derived, cropped)
- Slope and roughness rasters (derived, computed locally)
- Point queries for terrain inspector (derived)

**Processing:**
1. Downloaded MEGDR global tiles (IMG format with HDR/LBL metadata)
2. Cropped to Gale Crater bounds (135.5°–139.5°E, 4.2°–6.8°S)
3. Reprojected to Mars Equirectangular CRS (IAU 2000:104905)
4. NoData value (0) excluded from all calculations
5. Slope computed via Horn's method (3×3 window)
6. Roughness computed as standard deviation of elevation in 3×3 window

**Attribution:**
```
MGS MOLA MEGDR · NASA PDS Geosciences Node
Hillshade and colour ramp are derived products
NoData (0 m sentinel) excluded from analysis
```

## Derived Products (Generated by DHRUVION)

### Elevation Raster (Gale Crater Crop)

- **Source**: MOLA MEGDR 128 px/deg global
- **Processing**: `scripts/process_mola_gale.py`
- **Output**: GeoTIFF + PNG (data/processed/mola/gale/elevation.tif)
- **Resolution**: 463.06 m/pixel
- **Bounds**: 135.5°–139.5°E, 4.2°–6.8°S
- **Range**: −4,648 m to +1,412 m
- **Status**: **DERIVED**

### Slope Raster

- **Source**: MOLA elevation crop
- **Method**: Horn's algorithm (3×3 finite difference)
- **Output**: GeoTIFF + PNG (data/processed/mola/gale/slope.tif)
- **Units**: Degrees
- **Status**: **DERIVED**

### Roughness Raster

- **Source**: MOLA elevation crop
- **Method**: Standard deviation in 3×3 window
- **Output**: GeoTIFF + PNG (data/processed/mola/gale/roughness.tif)
- **Units**: Dimensionless (normalized)
- **Status**: **DERIVED**

## Simulated Mission Context

The following are **SIMULATED** for demonstration purposes only:

| Component | Status | Notes |
|-----------|--------|-------|
| Science target catalogue | SIMULATED | 3 demo targets, not verified observations |
| Hazard/obstruction data | SIMULATED | Rockfall scenario for emergency demo |
| Route geometries | SIMULATED | A* on prototype grid, limited coverage |
| Mission time budget | SIMULATED | 240 min with 30 min reserve |
| AI assistant responses | SIMULATED | Backend endpoint returns fallback |

**Never present these as verified data.**

## Unavailable Data

The following are explicitly marked **UNAVAILABLE**:

- Verified slope raster (not loaded in current build)
- Verified roughness raster (not loaded in current build)
- Observed hazard catalogue (no dataset connected)
- Verified science target catalogue (no API connected)
- Live rover telemetry (not a real-time system)

## Attribution Requirements

### For NASA Data
All NASA datasets are public domain but require attribution per NASA Media Guidelines:
- Credit the instrument, mission, and data provider
- Do not imply NASA endorsement
- State when visualizations are not live telemetry

### For DHRUVION Derived Products
```
Derived from [SOURCE] by DHRUVION prototype
Processing: [METHOD] · NoData excluded · Not certified for navigation
```

### In UI Components
Every map layer, feature, and report includes:
- Status badge (OBSERVED/DERIVED/SIMULATED/UNAVAILABLE)
- Source name and provider
- Link to full metadata in feature inspector

## Data Processing Scripts

| Script | Purpose | Input | Output |
|--------|---------|-------|--------|
| `scripts/process_mola.py` | Global MOLA processing | Raw IMG/HDR | Global GeoTIFF |
| `scripts/process_mola_gale.py` | Gale Crater crop + derivatives | Global MOLA | elevation.tif, slope.tif, roughness.tif |
| `scripts/build_landing_assets.py` | Landing page assets | CTX tiles, MOLA | Web-optimized JPGs |

## Known Limitations

1. **MOLA coverage gaps** - Poleward of 87° latitude has no data
2. **NoData = 0 exclusion** - Creates small holes in derived products
3. **CTX mosaic seams** - Block adjacency may show boundaries
4. **Prototype CRS** - Mars Equirectangular is a simplification
5. **No CRISM/THEMIS/HiRISE** - Not integrated in this build
